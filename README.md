# 📚 **my-blog-app**

Um blog interativo em desenvolvimento, construído com **Next.js**, **Prisma**, **Tailwind CSS** e **PostgreSQL**.

> **Status do projeto:** Em desenvolvimento 🚧

---

## 🌐 **Descrição**

O **my-blog-app** é uma aplicação para a criação e visualização de posts de blog com suporte a comentários. A proposta é desenvolver as minhas habilidades a partir da criação de uma plataforma dinâmica e moderna, onde os usuários possam criar e compartilhar suas ideias.

---

## 🛠️ **Tecnologias Utilizadas**

- **[Next.js](https://nextjs.org/):** Framework React para desenvolvimento de interfaces de usuário rápidas e escaláveis.
- **[Prisma](https://www.prisma.io/):** ORM para manipulação do banco de dados PostgreSQL com uma abordagem intuitiva e segura.
- **[Tailwind CSS](https://tailwindcss.com/):** Framework CSS utilitário para estilização rápida e responsiva.
- **[PostgreSQL](https://www.postgresql.org/):** Banco de dados relacional robusto e confiável.
